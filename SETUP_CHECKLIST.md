## 🚀 STEP 5: Start the App

### Windows Users:
- [ ] Opened TWO Command Prompt windows
- [ ] In first window: `cd Desktop\dialed-in-fitness\backend`
- [ ] In first window: `python -m uvicorn app.main:app --reload`
- [ ] Saw "Application startup complete"
- [ ] In second window: `cd Desktop\dialed-in-fitness\frontend`
- [ ] In second window: `streamlit run Home.py`
- [ ] Browser opened automatically to localhost:8501
- [ ] Saw the "Dialed In Fitness" homepage

### Mac Users:
- [ ] In Terminal: `chmod +x start.sh` (first time only)
- [ ] In Terminal: `./start.sh`
- [ ] Saw "Starting backend" and "Starting frontend"
- [ ] Browser opened automatically to localhost:8501
- [ ] Saw the "Dialed In Fitness" homepage

**The app is running!** ✓

## 💡 Pro Tips

**Things I learned:**

- Terminal windows must stay open while using app
- Data saves automatically when I click "Save Log"
- I can edit logs by going back to that date
- Rest days count as 100% if within my allowed rest days
- Forgiveness margins mean I don't have to be PERFECT
- The more I log, the better the Reports page gets
