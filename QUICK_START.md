# 🚀 Quick Start - One Page Summary

## For Non-Coders: 3 Steps to Get Running

### ⬇️ Step 1: Download (2 minutes)
```
1. Click the dialed-in-fitness folder link in this chat
2. Download it to your Desktop
3. Unzip if needed
```

### 🐍 Step 2: Install Python (5 minutes)
```
1. Go to: python.org/downloads
2. Click "Download Python"
3. Run installer
   ⚠️ WINDOWS: Check "Add Python to PATH"
4. Test it works:
   - Open terminal/command prompt
   - Type: python --version
   - See version number = SUCCESS!
```

### ▶️ Step 3: Run the App (5 minutes)

**Windows (requires TWO windows):**
```
Window 1:
  cd Desktop\dialed-in-fitness\backend
  python -m uvicorn app.main:app --reload

Window 2:
  cd Desktop\dialed-in-fitness\frontend
  streamlit run Home.py
```

**Mac (easy one-liner):**
```
cd Desktop/dialed-in-fitness
./start.sh
```

**Browser opens → YOU'RE RUNNING!** 🎉

## Scoring Quick Reference

**What counts most:**
- Workout volume (25%)
- Calories (20%)
- Everything else (55%)

**Your daily score factors in:**
- Did you hit your nutrition targets?
- Did you complete your workout volume?
- Did you get enough sleep, steps, water?
- Did you take your supplements?

**Color codes:**
- 🟢 Green (8.5+) = Dialed In!
- 🟡 Yellow (7.0-8.4) = Good
- 🔴 Red (<7.0) = Needs work

## Success Tips

1. **Log daily** - Even if imperfect
2. **Use forgiveness margins** - 3-5% wiggle room
3. **Don't skip workouts** - Biggest score impact
4. **Track for 7 days minimum** - See patterns emerge
5. **Aim for consistency** - Not perfection

**Goal:** 7+ out of 10 average = You're crushing it! 💪
